# Contributing to Stellar NFT App

Thank you for your interest in contributing to OrbitNFT — a Digital Art NFT platform built on the Stellar blockchain.

## Getting Started

1. Fork this repository
2. Clone your fork: git clone https://github.com/your-username/stellar-nft-app.git
3. Install dependencies: npm install
4. Start the dev server: npm start

## How to Contribute

- Browse open [Issues](https://github.com/orbitNFT-labs/stellar-nft-app/issues)
- Comment on an issue before starting work
- Create a branch: git checkout -b feature/your-feature-name
- Make your changes and commit: git commit -m "feat: describe your change"
- Push and open a Pull Request against main

## Code Style

- Use clear, descriptive variable names
- Keep components small and focused
- Comment complex logic

## Pull Request Guidelines

- Reference the issue number in your PR description (e.g. Closes #3)
- Include a short description of what changed and why
- Make sure npm run build passes before submitting

## Questions?

Open an issue or reach out via GitHub Discussions.
